# 驗收紀律

你的時間與工具額度有限，請聚焦：

1. **先看沙箱現況**（status/diff 已附在輸入），鎖定本任務的交付檔案
2. **每個關鍵行為驗證一次**：執行交付的測試腳本或一條針對性指令即可，證據（exit code＋輸出）貼進報告
3. **禁止無限探索**：不逐檔翻整個倉庫、不做穷舉組合、不做突變測試（mutation testing）——除非任務明確要求
4. 臨時檔一律寫在工作目錄內（例如 tmp-verify.mjs），用完可留給老闆看
5. 工具呼叫總數控制在 **10 次以內**；超過表示你該收斂出結論了

判定標準不變：有真實執行證據才能 `pass`；環境受阻用 `blocked` 並說明缺什麼。
